# Human Resource Information System (HRIS)

## Overview

The **Human Resource Information System (HRIS)** is a system that manage employee information and HR tasks in one place. It allows HR teams to store employee records, track attendance, manage payroll adjustments, and handle performance reviews.

The system helps reduce manual work, keep employee data organized, and make HR processes easier for both administrators and employees.

## Objectives

* Keep all employee information in one system
* Make HR tasks faster and easier
* Reduce paperwork and manual processes
* Allow employees to access their own information
* Help managers monitor employee performance

## Key Features

### Employee Management

Stores important information about employees.

**Features**

* Employee profiles
* Department and position assignment
* Employee records and documents
* Employment history

### Attendance Management

Tracks employee work attendance and absences.

**Features**

* Daily attendance records
* Work schedule tracking
* Leave requests
* Attendance reports

### Payroll 

Allows HR to manage changes in employee salary or deductions.

**Features**

* Salary Bonuses and Deduction
* Payroll change records
* Approval tracking

### Performance Evaluation

Helps managers review employee performance.

**Features**

* Performance reviews
* Key Performance Indicators (KPIs)
* Manager evaluations
* Feedback from supervisors

### Employee Self-Service Portal

Allows employees to access their own information.

**Features**

* View payslips
* Submit leave requests
* Check attendance records
* Update personal information
* Download important documents

### Activity Logs

Records actions done in the system.

**Features**

* User activity tracking
* System logs
* Record of changes for auditing

## Benefits

* Makes HR work more organized
* Reduces manual tasks
* Keeps employee information secure
* Helps managers track employee performance
* Gives employees easier access to their information

## Users

The system is used by:

* HR administrators
* Managers and supervisors
* Employees

## Conclusion

The HRIS helps companies manage employee information and HR tasks more efficiently. By using a digital system, HR teams can work faster, reduce errors, and provide better support to employees.
